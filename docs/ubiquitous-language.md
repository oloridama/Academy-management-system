Term           |           Defintion
--------------------------------------------------------------------
Prospect    ->   A person who has shown interest but has not yet registered
               
Registration   ->  The process of admitting a prospect and creating their student record.

Student   ->   A registered learner in the academy.

course    ->   The subject being taught (e.g., Python Programming).

Batch     ->   A scheduled delivery of a single course with dates, instructor, and timetable.

Class Session   ->   One scheduled teaching event wiithin a batch.

Attendance Record   ->   A student's attendance for one class session.

Assessment   ->   An assignment, quiz, project, or exam used to evaluate learning.
